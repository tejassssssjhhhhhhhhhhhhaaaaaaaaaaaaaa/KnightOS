# Completion Rules

After every completed task the AI must:

1. Mark the task complete.
2. Update SESSION_STATE.md.
3. Update NEXT_TASK.md.
4. Verify the project builds.
5. Continue immediately with the next unfinished task.

Never stop because a task has finished.
