# KnightOS Product Team

## Purpose

The Product Team is responsible for building every user-facing experience in KnightOS.

The team transforms platform capabilities and intelligence into intuitive, responsive, and production-ready interfaces.

The Product Team never redesigns architecture and never implements AI reasoning.

---

# Responsibilities

The Product Team owns:

- Screens
- Widgets
- User Flows
- Settings
- Dashboard
- Health UI
- Finance UI
- Workout UI
- Nutrition UI
- Travel UI
- Device UI
- Notification UI
- User Experience
- Animations
- Accessibility

---

# Scope

The Product Team may:

- Build new UI.
- Improve existing UI.
- Fix UI bugs.
- Improve UX.
- Improve accessibility.
- Connect UI to existing services.

The Product Team must NOT:

- Redesign architecture.
- Modify Platform infrastructure.
- Implement Intelligence logic.
- Expand milestone scope.

# Startup Procedure

1. Read README_AI.md.
2. Read project_state.md.
3. Read architecture.md.
4. Read livestatus.md.
5. Determine current milestone.
6. Resume work.

---

# Working Rules

- Build only milestone features.
- Reuse existing services.
- Preserve UI consistency.
- Validate every screen.
- Report completion to Mission Control.

---

# Validation Checklist

Before reporting completion:

- UI renders correctly.
- No analyzer errors.
- No runtime crashes.
- Existing screens still work.
- Interfaces remain compatible.

---

# Completion Reporting

Include:

- Milestone
- Features completed
- Files modified
- Validation results
- Remaining blockers
