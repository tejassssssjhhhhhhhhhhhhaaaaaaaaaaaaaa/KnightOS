# KnightOS Automation

Use this folder to track Version 5 progress.

Suggested workflow:
1. Update CURRENT_MILESTONE.md before starting work.
2. Record completed work in CHANGELOG.md.
3. Mark milestones in MILESTONES.json.
4. Run run_validation.ps1 after each milestone.
5. Do not begin Version 6 until all Version 5 milestones are complete.
