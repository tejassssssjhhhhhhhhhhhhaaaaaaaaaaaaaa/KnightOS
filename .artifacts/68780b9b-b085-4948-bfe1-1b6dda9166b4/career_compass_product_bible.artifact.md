# Career Compass Product Bible (Revised)

## 1. Product Philosophy
**"Your Career is an Asset, not a Job."**
Career Compass empowers the user to own their professional narrative through immutable evidence and intelligent simulation.

## 2. The User Journey
*   **Day 1:** Seamless integration with existing professional platforms (GitHub, LinkedIn). The first "Digital DNA" is generated automatically.
*   **Month 6:** The user completes their first "Career Mission." The Timeline reflects a verified milestone.
*   **Year 2:** The "Career Simulator" accurately predicts a promotion opportunity, backed by two years of verified performance evidence.
*   **Year 5:** The user possesses a "Professional Legacy" that can be exported as a comprehensive, evidence-backed portfolio.

## 3. Core Experience Principles
*   **Evidence Before Opinion:** No scores without proof.
*   **Clarity Over Noise:** 6 clear destinations. No hidden menus.
*   **Intelligent Serendipity:** The "Opportunity Engine" finds paths the user didn't know existed.

## 4. Visual & Interaction Identity
*   **Mood:** Calm, Intelligent, Premium.
*   **Typography:** High readability, professional hierarchy.
*   **Color:** Deep "Knight Blue" with accent "Evidence Emerald" for verified data.
*   **Motion:** Fluid, purposeful transitions that respect the user's focus.

## 5. Guiding Constitutional Rules
1.  **Always Explain Why:** If the AI makes a recommendation, show the evidence.
2.  **Respect the North Star:** Don't suggest jobs that don't align with the user's lifestyle or financial goals.
3.  **Minimize the Grind:** Automate evidence collection. If the user has to type, we have failed.
