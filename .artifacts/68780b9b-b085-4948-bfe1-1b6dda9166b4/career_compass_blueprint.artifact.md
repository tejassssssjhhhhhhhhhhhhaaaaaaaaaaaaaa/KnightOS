# Career Compass Engineering Blueprint (Revised)

**Status:** ARCHITECTURAL DRAFT
**Alignment:** KnightOS Core Constitution

## 1. System Vision (Refined)
Career Compass is the evidence-based "Professional Operating System" for the KnightOS ecosystem. It leverages the **KnightOS Core** to turn professional activity into a verified legacy.

## 2. Information Architecture (The 6 Destinations)

1.  **Command Center (Home)**
    *   **Purpose:** Immediate focus and intelligence.
    *   **Components:** Daily Career Missions, Current "North Star" Progress, High-Impact Recommendations.
2.  **The Legacy (Timeline)**
    *   **Purpose:** The evidence-backed professional story.
    *   **Components:** Universal Timeline integration, Milestone visualization, Achievement history.
3.  **The DNA (Skills)**
    *   **Purpose:** Skill intelligence and growth.
    *   **Components:** Skill Nebula (3D Visualization), Verification Status, Decay Tracking, Growth Trends.
4.  **Decision Lab (Simulations)**
    *   **Purpose:** Evaluating scenarios using the Simulator Engine.
    *   **Components:** Promotion Simulator, Switch Simulator, ROI Calculator (Finance integration).
5.  **Growth Engine (Opportunities)**
    *   **Purpose:** Discovering the next step.
    *   **Components:** Learning Marketplace, Job Feed, Certification Center, Internal Openings.
6.  **The Vault (Evidence)**
    *   *Purpose:** Repository of truth.
    *   **Components:** Project Gallery, Certificate Storage, Performance Review archive, Verification logs.

## 3. Domain Model (Career Specific)

*   **Skill:** (Node in Evidence Graph) - Knowledge, Ability, Experience, Verification Status.
*   **Evidence:** (Node) - Link between a Skill and a source (Project, Cert, Feedback).
*   **Project:** (Entity) - Contextual container for work achievements.
*   **Promotion Scenario:** (Simulation) - A hypothesis tested against the Simulator Engine.

## 4. AI Architecture (Knight Intelligence Specialization)

*   **Skill Scoring Engine:** Calculates "Practical Ability" based on evidence density.
*   **Simulator Engine:** Uses probabilistic models to estimate "Promotion Readiness" with confidence intervals.
*   **Mission Planner:** Decomposes long-term goals into measurable Career Missions.

## 5. Data Flow (Zero-Touch)

1.  **Ingestion:** Knight Core Integration Hub watches GitHub (commits), Calendar (meetings), and LinkedIn (updates).
2.  **Processing:** Knight Intelligence identifies "Potential Evidence" and prompts the user for "Verification."
3.  **Scoring:** Verified evidence updates the Skill DNA and Timeline.
4.  **Reasoning:** Cross-domain intelligence checks if "Stress" (Health) or "Budget" (Finance) impacts the current Career Mission.

## 6. Verification Plan
*   **Manual:** User uploads document.
*   **Automated:** GitHub commit patterns, Certification API validation.
*   **Social:** Manager/Peer feedback integration (Future).
