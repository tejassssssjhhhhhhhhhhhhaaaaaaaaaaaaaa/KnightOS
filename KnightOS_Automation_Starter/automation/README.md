# KnightOS Version 5 Automation

## Objective
Complete KnightOS Version 5 from start to finish using a single engineering workflow.

## Engineering Rules

1. Never skip validation.
2. Complete only one milestone at a time.
3. Every completed milestone must pass:
   - flutter analyze
   - flutter test
   - Build verification
   - Regression verification
   - Physical device validation
4. Never introduce placeholder implementations.
5. Never break previously completed functionality.
6. Always fix failures before continuing.
7. Maintain project-wide consistency.
8. Update all automation files after every milestone.
9. Do not begin Version 6.
10. Stop only when every Version 5 milestone has been completed, validated, integrated, and the application is release-ready.

## Completion Definition

Version 5 is complete only when:

- All milestones completed
- All integrations finished
- No analyzer errors
- No failing tests
- Release build succeeds
- Physical device validation completed
- No known regressions
- Documentation updated
- Project marked READY FOR RELEASE
