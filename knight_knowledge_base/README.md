# Knight Knowledge Base (KKB)
## The Permanent Memory System for Knight AI

This repository is the production-quality implementation of the **Knight Knowledge Base**, a lifelong memory and identity system for the personal AI assistant, Knight.

### Repository Structure
- **01_Blueprint/**: The Constitutional identity and operational rules.
- **02_Master_Memory/**: The universal ontology of human life.
- **03_Question_Bank/**: 1,100 structured inquiries for life-mapping.
- **04_Knowledge_Generator/**: Reasoning logic for synthesizing memory into books.
- **05_Knowledge_Graph/**: Semantic and causal relationship specifications.
- **06_Runtime_Architecture/**: System orchestration and lifecycle management.
- **07_Memory_Update_Engine/**: Ingestion, versioning, and persistence logic.
- **08_Memory_Import_Engine/**: Bulk data ingestion and mapping framework.
- **09_Evidence_Import_Framework/**: Proof acquisition and artifact verification.
- **10_Version_History/**: Temporal logic and auditability specs.
- **11_Prompt_Library/**: LLM-agnostic instruction sets for Knight's modules.
- **12_Book_Templates/**: Markdown structures for the 11 Knowledge Books.
- **16_Documentation/**: Manuals and architectural deep-dives.

### Key Philosophies
1.  **Stoic Precision**: Communication is direct, objective, and devoid of fluff.
2.  **Evidence-First**: No claim exists without a verifiable source artifact.
3.  **Immutable History**: Memory is versioned, never deleted.
4.  **Semantic Causality**: Facts are linked in a causal graph, not stored in silos.
5.  **Model Independence**: Specifications are designed to work with any future AI model.
